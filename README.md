# ParadisePaints

Мод для малювання картин на сервері ParadiseCraft:

**`play.paradise-craft.com`**

## Завантаження

[Завантажити ParadisePaints](https://github.com/ParadiseCraft/ParadisePaints-Mod/releases)

Оберіть JAR для своєї версії Minecraft:

- `1.21.11`
- `26.1.2`
- `26.2`

## Як встановити

1. Встановіть [Fabric Loader](https://fabricmc.net/use/installer/) для своєї версії Minecraft.
2. Завантажте відповідні версії [Fabric API](https://modrinth.com/mod/fabric-api) та ParadisePaints.
3. Покладіть обидва JAR-файли у папку `mods`.
4. Запустіть Minecraft через профіль Fabric і приєднайтеся до `play.paradise-craft.com`.

Якщо мод не запускається, перевірте відповідність версій Minecraft, Fabric API та ParadisePaints.
